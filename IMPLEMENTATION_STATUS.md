# Autonomous production implementation checkpoint

## Implemented and tested

- Persistent SQLite tasks, restart-safe ordering, idempotent start and audit events.
- Project-relative evidence files with SHA-256 identity and downstream reopening after changes.
- Content-addressed evidence snapshots preserve previous bytes after working files change; changing the brief reopens tasks without resetting consumed budgets.
- Stage-specific contract fields, six source-verified PNG proposals with distinct rendered content and pairwise silhouette diagnostics, and eleven-criterion review completeness. Proposal and construction dimensions must match the managed native_size contract.
- Every pending task includes category-specific failure checks, a visual inspection protocol and targeted repair instructions; review tasks include the eleven-criterion rubric.
- Nonempty image evidence for construction/review and JSON source evidence for construction.
- Native PNG and atlas construction is rerendered from the submitted fresh source and compared pixel-for-pixel; atlas manifests must preserve source timing and clips. GIF previews are verified after palette conversion and timing quantization. Reviews must include the exact constructed artifact evidence.
- Declared reviewer-context separation; these declarations are not authenticated host isolation.
- Artifact-bound reviewer packets expose native and 4x views for every frame without author or peer-review arguments. Submissions must identify the current packet, cover every view and include its hash-bound evidence; coverage declarations are not host observation attestations.
- Failed review scores reopen construction and preserve review history and consumed budgets.
- Three consecutive reviews with the same failing criteria reopen structural alternatives; budget-exhaustion diagnostics retain the latest defects.
- Repair-aware revision identities block unchanged rejected content and metadata-only responses to artistic defects under the same delivery contract. Genuine runtime-only repairs remain possible for technical/game-readiness defects; filenames, PNG text and transparent padding do not create new visual content.
- Construction/review submission quotas and explicit blocked status on exhaustion.
- Universal manifest validation of texture hashes, actual frame regions, anchors, timing and clip references.
- Direct `render --manifest` export derives atlas layout, texture hashes, timing and clips from rendered output, requiring explicit runtime anchors. Per-frame overrides, sockets and functional regions follow padding/scaling; provenance verifies those transformed coordinates too.
- Exported clip timing traces, explicitly reporting unverified runtime behaviors.
- Reference scene compositor consumes only exported manifests/textures and emits native PNGs plus timing, pivot placement and stable Y-sort traces.
- Validated convex functional regions distinguish collision, hit, hurt, interaction and occluder roles; contextual traces report positive-area overlaps without treating boundary contact as penetration.
- Explicit actor timelines reject undeclared state changes and premature interruption of protected actions; position updates preserve clip timing unless a restart is requested.
- Optional structured delivery contracts require named views/actions/states and explicit valid combinations in reachable manifest frames. Distinct-view checks reject identical view frame sets when requested; unreachable atlas content cannot satisfy delivery coverage.
- Tile diagnostics produce native/4x repetition mosaics, every legal Wang16 edge-pair comparison and premultiplied edge-delta reports. Spatial visual continuity, temporal seams and Blob47 coverage remain unverified.
- Approximate silhouette comparison normalized for padding and scale, with reflection checks.
- Empty artwork cannot pass style fidelity checks.
- Generator help and field linting share explicit parameter declarations; managed sources reject unknown operations/fields throughout frames, definitions, parts and post-processing, including expanded imports.
- Fresh generation rechecks imported definitions, so imports cannot smuggle in load_png or inheritance reuse.
- PNG metadata and Godot exports preserve explicit per-frame durations and named clips; GIF previews preserve holds within GIF timing limits.
- Procedural library included in wheel/sdist builds and resolved from installed packages.
- Named assembly parts with validated parent graphs, inherited offsets, deterministic draw order, material labels and transform-aware exported origins.
- Optional versioned broadleaf growth graphs drive trunk, roots, forks and canopy supports for six distinct architectures. Trunk-only inspection and native-size/seed tests cover structure independently of foliage color; legacy trees remain unchanged without opt-in.
- Growth graph topology/geometry/reflection comparisons ignore labels, translation and scale; managed proposal reports include these structural comparisons alongside silhouettes.
- Pending tasks return their required brief, contract, selected proposal and comparison inputs, allowing an agent to resume without recovering previous chat messages. Reviewer tasks keep author-side inputs excluded.

## Current limits

The managed queue never approves production. Proposal pixel differences and similarity diagnostics do not establish meaningful structural diversity; that still requires visual review. Reviewer declarations do not prove isolated contexts or actual perception. The reference runtime renders pivot placement, sorting, functional-region overlap and declared state changes; it does not yet solve movement collisions, validate acting, blend transitions or verify tile seams. These checks remain necessary before enabling release.
